# E-Commerce Analytics Dashboard

A high-end React Business Intelligence (BI) tool that transforms raw CSV transaction data into gorgeous, interactive business insights using Recharts, Tailwind CSS, and precise scroll-reveal animations.

## Key Features
- **Data Upload**: Dropzone uploading for parsing raw e-commerce CSV datasets directly in-browser.
- **Scroll Reveal Animations**: Custom `useInView` hooks trigger Recharts draw animations strictly when users scroll charts into the viewport.
- **Glassmorphic UI**: Premium deep dark UI (`#020617` background) with backdrop filters, gradient borders, and responsive design.

## Technologies Built With
- **Frontend Framework**: React, TypeScript, Vite
- **Styling**: Tailwind CSS 
- **Data Visualization**: Recharts (with completely customized gridlines, axes, and translucent tooltips)
- **Data Processing**: PapaParse, Lodash

## Running Locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
